# Kontrola spójności pakietu

Data 13 września 2026. Wykonano 3386 asercji dotyczących plików danych i scenariuszy. Wszystkie przeszły.

- 31 unikalnych ćwiczeń, 11 jednostek bazowych, 7 układów tygodnia.
- 7 przykładów po 28 dni, łącznie 92 sesji siłowych.
- Zgodne identyfikatory, sprzęt, zakresy, zapis stron i brak wymyślonych ciężarów.
- Ciągłość dat, liczba sesji, czas obliczony ze wzoru, limity serii i odstępy głównych mięśni.
- Ponowne obliczenie sum tygodniowych i odczyt wszystkich JSON.

Nie wykonano testów przyszłej aplikacji, przeglądu klinicznego ani pilotażu treningowego. Schematy JSON wymagają walidatora Draft 2020-12 przy wdrożeniu; tutaj sprawdzono składnię JSON i asercje domenowe, bez biblioteki JSON Schema. Czas sesji jest oszacowaniem, nie pomiarem.

Przykłady zakładają dobry stan regeneracji, więc tydzień 4 nie jest odciążony. Adaptację i sytuacje blokujące opisują dokument oraz przypadki akceptacyjne. Użytkownik aplikacji musi przejść rzeczywisty wywiad.
